# Data — Smart Air Pollution Monitoring Portal

This folder holds all data files used by the backend.

## Subfolder Structure

```
data/
├── raw/          # Untouched downloads from OpenAQ or OGD India
│                 # Never modified; kept for reference and reproducibility
│
├── cleaned/      # Preprocessed/normalised CSV files ready for the backend
│                 # Column names match the PollutionReading data model
│
├── fallback/     # Static datasets served when the live API is unavailable
│                 # One CSV per city: delhi.csv, mumbai.csv, prayagraj.csv, ...
│                 # All rows carry data_type = FALLBACK
│
└── cache/        # Auto-generated by the backend; do not edit manually
                  # JSON files named by endpoint + parameters + timestamp
                  # Safe to delete to force a fresh API fetch
```

## Data Integrity Policy

- Raw files are never modified.
- Cleaned files never fill null pollutant values with estimates.
- All fallback CSVs have a `data_type` column set to `FALLBACK`.
- The `cache/` folder is excluded from version control (see .gitignore).

## File Naming Convention

| File | Contents |
|---|---|
| `fallback/<city_id>.csv` | Pre-downloaded readings for a city |
| `cache/<endpoint>_<params>.json` | Cached API response |
| `verified_stations.json` | Confirmed OpenAQ location_ids (created in Step 2) |
