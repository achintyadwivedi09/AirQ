# API Contract — Smart Air Pollution Monitoring Portal

**Base URL (local development):** `http://localhost:5000/api/v1`  
**Response format:** JSON  
**Authentication:** None (internal API; frontend and backend run on the same machine)

> This document defines the *intended* API. Endpoints are not all implemented yet.
> Implementation will happen in Step 2. This contract drives the backend design.

---

## Common Response Fields

Every response body from this API includes:

| Field | Type | Description |
|---|---|---|
| `status` | string | `"ok"` or `"error"` |
| `data_type` | string | `"REAL"`, `"SIMULATED"`, or `"FALLBACK"` — applies to the data being returned |
| `cached` | boolean | `true` if this response was served from the local file cache |
| `timestamp` | string (ISO 8601) | When this response was generated by the backend |

On error:

```json
{
  "status": "error",
  "error": "Description of what went wrong",
  "timestamp": "2025-08-14T16:00:00Z"
}
```

## Endpoint 1 — List Supported Cities

**`GET /cities`**

Returns the list of cities the backend is configured to support.

### Purpose
Allows the frontend to populate the city-selector dropdown without hardcoding city names.

### Query Parameters
None.

### Example Response

```json
{
  "status": "ok",
  "data_type": "REAL",
  "cached": false,
  "timestamp": "2025-08-14T16:00:00Z",
  "cities": [
    {
      "id": "delhi",
      "name": "Delhi",
      "state": "Delhi",
      "lat": 28.6139,
      "lon": 77.2090
    },
    {
      "id": "prayagraj",
      "name": "Prayagraj",
      "state": "Uttar Pradesh",
      "lat": 25.4358,
      "lon": 81.8464,
      "note": "Station availability subject to OpenAQ coverage"
    }
  ]
}
```

## Endpoint 2 — List Stations for a City

**`GET /stations?city=<city_id>`**

Returns monitoring stations available for the specified city.

### Purpose
Lets the user pick a specific monitoring station within a city.

### Query Parameters

| Parameter | Required | Type | Description |
|---|---|---|---|
| `city` | Yes | string | City ID (e.g., `delhi`, `prayagraj`) |

### Example Response

```json
{
  "status": "ok",
  "data_type": "REAL",
  "cached": true,
  "timestamp": "2025-08-14T16:00:00Z",
  "city": "prayagraj",
  "stations": [
    {
      "station_id": "openaq-12345",
      "name": "Nagar Nigam, Civil Lines",
      "city": "Prayagraj",
      "lat": 25.4516,
      "lon": 81.8415,
      "provider": "CPCB"
    },
    {
      "station_id": "openaq-12346",
      "name": "MNNIT Shivkuti",
      "city": "Prayagraj",
      "lat": 25.4888,
      "lon": 81.8626,
      "provider": "CPCB"
    }
  ]
}
```

If no stations are found:
```json
{
  "status": "ok",
  "data_type": "FALLBACK",
  "stations": [],
  "message": "No live stations found for this city. Using fallback data."
}
```

## Endpoint 3 — Latest Readings

**`GET /readings/latest?city=<city_id>&station=<station_id>`**

Returns the most recent pollution reading for a city or a specific station.

### Purpose
Powers the main AQI card and pollutant summary on the dashboard.

### Query Parameters

| Parameter | Required | Type | Description |
|---|---|---|---|
| `city` | Yes | string | City ID |
| `station` | No | string | Station ID; if omitted, returns aggregate/best-available for the city |
| `refresh` | No | boolean | If `true`, bypass cache and fetch live from OpenAQ |

### Example Response

```json
{
  "status": "ok",
  "data_type": "REAL",
  "cached": false,
  "timestamp": "2025-08-14T16:00:00Z",
  "reading": {
    "city": "Prayagraj",
    "station_id": "openaq-12345",
    "station_name": "Nagar Nigam, Civil Lines",
    "lat": 25.4516,
    "lon": 81.8415,
    "reading_timestamp": "2025-08-14T15:45:00Z",
    "aqi": 142,
    "aqi_category": "Unhealthy for Sensitive Groups",
    "data_type": "REAL",
    "source": "OpenAQ/CPCB",
    "pollutants": {
      "pm25":  { "value": 58.3,  "unit": "µg/m³" },
      "pm10":  { "value": 112.0, "unit": "µg/m³" },
      "no2":   { "value": 34.5,  "unit": "µg/m³" },
      "so2":   { "value": null,  "unit": "µg/m³" },
      "co":    { "value": 1.2,   "unit": "mg/m³" },
      "o3":    { "value": null,  "unit": "µg/m³" }
    }
  }
}
```

Note: `null` means the pollutant was not reported; the frontend hides those cards.

## Endpoint 4 — Historical Readings

**`GET /readings/history?city=<city_id>&station=<station_id>&days=<n>`**

Returns a time series of readings for charting.

### Purpose
Powers the 7-day trend chart on the dashboard.

### Query Parameters

| Parameter | Required | Type | Default | Description |
|---|---|---|---|---|
| `city` | Yes | string | — | City ID |
| `station` | No | string | — | Station ID |
| `days` | No | integer | 7 | Number of past days to return |
| `pollutant` | No | string | `pm25` | Which pollutant to return (`pm25`, `pm10`, `no2`, etc.) |

### Example Response

```json
{
  "status": "ok",
  "data_type": "REAL",
  "cached": true,
  "timestamp": "2025-08-14T16:00:00Z",
  "city": "delhi",
  "pollutant": "pm25",
  "unit": "µg/m³",
  "readings": [
    { "timestamp": "2025-08-08T00:00:00Z", "value": 72.1 },
    { "timestamp": "2025-08-09T00:00:00Z", "value": 65.0 },
    { "timestamp": "2025-08-10T00:00:00Z", "value": null },
    { "timestamp": "2025-08-11T00:00:00Z", "value": 88.4 }
  ]
}
```

Note: `null` entries mean data was not reported for that period; chart should show a gap.

### Purpose

```json
  "cached": true,

  "city": "mumbai",
  "period_days": 7,

    "pm25": { "min": 22.1, "max": 98.4, "avg": 54.7, "unit": "µg/m³" },

    "no2":  { "min": null, "max": null, "avg": null, "unit": "µg/m³" }

}
```

## Error Codes

| HTTP Status | Meaning |
|---|---|
| 200 | Success |
| 400 | Bad request (missing required parameter) |
| 404 | City or station not found |
| 503 | External API unavailable; fallback being used |
